# MeetKey Case v3

`MeetKey_Case_v3.stl`은 MeetKey Recorder의 최종 조립에 사용한 3D 출력용 케이스 모델입니다.

## 설계 의도

- 5인치 디스플레이를 전면에 비스듬히 배치해 책상 위에서 바로 조작할 수 있게 함
- Anker PowerConf 마이크 받침부를 디스플레이 높이까지 올려, 디스플레이 프레임이 마이크로 들어오는 소리를 가리지 않게 함
- 후면부는 마이크 높이 확보와 라즈베리파이/케이블 정리를 함께 고려
- 회의실에 놓아도 부품 조합처럼 보이지 않고 하나의 전용 장치처럼 보이는 외형을 목표로 함

## 출력 과정

총 3번 출력했습니다.

1. 1차 출력: 디스플레이 결합부만 작게 출력해 화면 공차 확인
2. 2차 출력: 수정된 결합부를 다시 출력해 끼움 상태 재확인
3. 3차 출력: 최종 v3 전체 케이스 출력 후 라즈베리파이, 디스플레이, 마이크 결합

초기 1, 2차 출력에서는 전체 케이스를 뽑지 않고 화면 결합부만 테스트해 필라멘트 낭비를 줄였습니다.
